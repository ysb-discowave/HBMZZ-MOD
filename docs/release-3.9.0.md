# HBMZZ 3.9.0 — 贴墙实体屏、实时调节，和一条紧急停堆指令

> HBMZZ 3.9.0，面向 Minecraft 1.12.2 / Forge 14.23.5.2847。
> 这一版修好了神盾监控屏的三个老毛病（侧视像空气、几何不是真实时、温度突然不刷新），
> 连接工具绑定后直接进设置窗口，并新增操作员指令 `/aegis scram` 做紧急停堆。

| 内容 | 说明 |
|---|---|
| 侧视实体屏 | 外壳加厚到约 0.18 格，四面分色 + 青色高光棱，斜着/侧着看是有厚度的显示器 |
| 几何实时 | 菜单里调倾斜角/宽/高，画面和数值下一帧就变、存档同步写，不用退出菜单 |
| 温度修复 | 放宽 DFC 核心识别（CE/Cursed 改名也能认出），找不到核心时写诊断日志 |
| 连接工具 | 绑定核心后自动打开设置窗口，可直接接着调参数 |
| 自动停堆 | `/aegis scram`：每秒降 2000°C，温度失控上升时瞬间归零 |
| 版本号 | 三处版本戳统一为 3.9.0，产物 `hbmzz-3.9.0.jar` |

## 一、屏幕侧看不再是空气

旧外壳又薄又黑，从侧面看几乎看不见。现在它是一台有厚度的显示器：加厚背板、四面按明暗分别上色、四条深度棱带青色高光。贴墙的安装方式不变，但从任何角度都能看出它是实体。

## 二、几何调节实时生效

右键菜单调倾斜角（−45°~+45°）、宽、高（0.5~2.0 格）时，客户端先本地更新预览，画面和读数下一帧就变；同一个值再发服务端存档并广播。两端用同一套范围钳制，回包不会让数值跳回去。鼠标按钮和 Z/X、[ / ]、- / = 快捷键都一样。

## 三、温度不刷新的修复

现场日志显示模组已加载，却没有任何采样记录——根因是 DFC 核心的类名在 CE/Cursed 环境下对不上，自动扫描找不到核心。现在核心识别除了精确类名，还会用 `getDFCTemperature` 等访问器和 `heat`/`field` 字段特征来判断，改名也能认出。找不到核心时会写一条带坐标和诊断信息的日志，方便定位。

## 四、连接工具绑定后自动进菜单

用神盾连接工具绑定核心后，会直接打开终端设置窗口，可以马上接着调倾斜、宽、高，不再只丢一句"绑定成功"。

## 五、自动停堆指令 `/aegis scram`

操作员指令（需权限等级 2）：

- `/aegis scram` —— 对附近最近的 DFC 核心启动停堆。
- `/aegis scram status` —— 查看停堆中的核心和温度。
- `/aegis scram off` —— 解除当前世界的停堆。

启动后每秒把核心温度压低 2000°C；如果温度不降反升（压不住了），直接瞬间归零。这是一条应急刹车，通过写核心温度字段实现，不替代反应堆自身的控制逻辑。

## 六、安装

| 3 | 独立配置在 `config/hbmzz-aegis.cfg` |
| 4 | 换 jar 后重启即可，老档兼容 |
