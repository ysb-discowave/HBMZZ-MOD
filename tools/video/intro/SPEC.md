# HBMZZ 片头 — 视觉分镜与技术规范（SPEC）

本文件是 `tools/video/intro/` 下片头成片的**唯一可执行规格**。它只描述画面与
交付契约，不修改 `docs/assets/brand/**` 中的任何文件——那份目录是品牌资产的
唯一真相，本片头只是它的**动画化演绎**，所有几何、颜色都从那里派生。

实现方（intro-build / intro-package）应按本文件逐条落地；验收方按第 12 节清单
逐条核对。任何与品牌资产冲突的临时美术决定，以品牌 SVG 为准。

---

## 1. 技术基线

| 项 | 值 |
|---|---|
| 总时长 | **8.000 s**（= 192 / 24，严格） |
| 分辨率 | **960 × 540**（与播放器 `videoMaxWidth/Height` 上限一致，见 `tools/video/pack.py`） |
| 帧率 | **24 fps**（恒定，非可变帧率） |
| 总帧数 | **192 帧** |
| 音轨 | **无**。成片 mp4 不带音频流，包内 `meta.json` 省略 `audio` 字段。 |
| 背景 | 恒定深底 `#0a0c0f`，全片不变、不加渐变。 |

**帧号约定**：帧号采用 1-based，对应文件名 `f000001.jpg` … `f000192.jpg`。
第 n 帧的呈现时刻为 `t = (n − 1) / 24` 秒；末帧 `t = 191/24 = 7.9583 s`，
`192/24 = 8.000 s` 是总时长。所有时间区间在本文档中同时给出秒与帧号，
边界秒数（2.2 s、6.8 s）取**最接近的帧**作为阶段切换点，并在表中注明。

**可选音效（仅建议，非强制）**：若后续想加极简反馈，建议一条 0.4 s 的
低频 "咔哒" 落在重组到位帧（帧 116，t≈4.79 s），音量 ≤ −24 dB。此项不纳入
验收，也不得改变"无音轨"的交付契约；加则另出带音版，默认交付仍为静音版。

## 2. 统一视觉风格

- **只用四种品牌色**，禁止第五种彩色：

  | 角色 | 色值 | 用途 |
  |---|---|---|
  | 钢板 | `#e6ecf3` | 屏框描边、H 两根立柱、HBMZZ 文字 |
  | 琥珀 | `#f5a524` | 横杠、下划线、唯一外发光色 |
  | 螺钉 | `#48525f` | 四角螺钉；副标若出现也用此色 |
  | 墨（底） | `#0a0c0f` | 全片背景 |

- **不要** lens flare、粒子雨、星尘、彩虹/多色渐变、扫描线噪点、镜头抖动、
  色差（chromatic aberration）等与品牌工业风不符的效果。
- 发光只允许琥珀 `#f5a524` 的**柔和外发光**，以及钢色的极弱描边补光（见 8.5）；
  半径受限、强度受限，且不得盖掉原有清晰线条。
- 整体气质：冷静、精确、机械感。运动用 easing 而非匀速，落点干脆。

## 5. 阶段一：开场引入（帧 1 – 53）

1. **帧 1（t=0）不是黑屏**：背景已是 `#0a0c0f`，屏框描边从起点开始出现一小段
   （dashoffset 已略小于满值），确保首帧即可见笔画（验收 1）。
2. **屏框描边**：用一条圆角矩形 `path`，设 `pathLength="1"`、
   `stroke="#e6ecf3"`、`stroke-width="3.5"`、`fill="none"`、
   `stroke-dasharray="1"`、`stroke-dashoffset` 从 **1 → 0**，
   起笔点设在左上角、顺时针绘制。时间 **帧 1 – 48（t≈0–1.96 s）**，
   easing = `easeInOutCubic`。
3. **内容淡入**：四枚螺钉、两根立柱、琥珀横杠的 `opacity` 从 **0 → 1**，
   时间 **帧 30 – 52（t≈1.21–2.13 s）**，easing = `easeOutCubic`；
   横杠始终不消失（验收 4），淡入完成后即为完整主标。
4. **帧 53**：完整主标静止呈现一帧，作为拆解前的视觉锚点。

## 6. 阶段二：Logo 动态变形（帧 54 – 164）

### 6.1 子阶段 2a — 局部拆解（帧 54 – 82，2.208–3.375 s）

11 个原子各自从原坐标出发，位移 + 旋转同时进行；位移用 CSS/SVG `transform`
（围绕各原子自身中心旋转），easing = `easeOutCubic`。方向以**屏幕方向**描述
（SVG 中 y 向下为正，故"屏幕上"= SVG −y）：

| 部件 | 飞散方向（屏幕） | 位移 | 旋转（绕自身中心） |
|---|---|---|---|
| 屏框上边 | 上（SVG −y） | 14 单位 | −6° |
| 屏框下边 | 下（SVG +y） | 14 单位 | +6° |
| 屏框左边 | 左（SVG −x） | 14 单位 | +6° |
| 屏框右边 | 右（SVG +x） | 14 单位 | −6° |
| 螺钉 左上 | 左上（−x, −y） | 18 单位 | 180° |
| 螺钉 右上 | 右上（+x, −y） | 18 单位 | 180° |
| 螺钉 左下 | 左下（−x, +y） | 18 单位 | 180° |
| 螺钉 右下 | 右下（+x, +y） | 18 单位 | 180° |
| H 左立柱 | 左（−x） | 10 单位 | −12° |
| H 右立柱 | 右（+x） | 10 单位 | +12° |
| 琥珀横杠 | 右上（+x, −y） | 16 单位 | −4° |

- 屏框四边向外"张开"形成断框，是本节最显眼的读点。
- **琥珀横杠全程保持 `#f5a524` 且不透明度 = 1**（验收 4）：它飞散但不淡出、
  不被任何其他图层遮挡，也不改变色相。
- 螺钉旋转 180° 后是同一形状，视觉上是"翻面飞出"，符合机械感。

### 6.2 子阶段 2b — 重组变形（帧 83 – 116，3.417–4.792 s）

- 所有 11 个原子以 `easeInOutCubic` 从 2a 的散开状态**回到第 3.1 节的精确原始
  坐标**，旋转归零、`opacity` 归 1。
- 重组的回归目标**只能是**第 3.1 节表格里的 64 网格数值，不得凭肉眼摆位。
- 为强调"咔哒归位"，可在末端 3–4 帧加入幅度 ≤ 0.6 单位的极轻过冲
  （overshoot），但必须由同一条连续曲线产生，**不得出现瞬移或跳帧**（验收 6）。
- 帧 116 时主标完全复原（可作为极简音效的落点，见 1 节）。

### 6.3 子阶段 2c — 缩放推进（帧 117 – 145，4.833–6.000 s）

- 把已复原的主标作为一个整体，绕**画面中心 (480, 270)** 等比缩放：
  **scale `1.00× → 1.18×`**。
- easing 强制为 **`easeInOutCubic`**（或数学等价的 cubic：`t<0.5 ? 4t³ : 1−(−2t+2)³/2`）。
  首尾速度为零，避免起停突兀（验收 11）。
- 缩放全程保持深底，不裁切、不位移出安全区；屏框边缘离画布边缘 ≥ 8%（README 规则）。

### 6.4 子阶段 2d — 发光强化（帧 146 – 164，6.042–6.792 s）

- 对**琥珀横杠**加柔和外发光：颜色 `#f5a524`，模糊半径对应屏幕约 **5–6 px**
  （若用 SVG `feGaussianBlur`，`stdDeviation ≈ 2.5`），强度 `opacity 0 → 0.28`
  （`easeOutCubic`）。
- 对**钢色屏框描边**仅加极弱补光：`#e6ecf3`，半径约 3 px（`stdDeviation ≈ 1.5`），
  `opacity 0 → 0.10`。**不加大、不加第二个发光层**（README 明确"不是发光特效，别加大"）。
- **防糊关键**：发光层画在**清晰原图之下**——先渲染光晕，再把原始锐利的描边、
  立柱、横杠叠在其上。钢色细节与 3.5 单位描边始终锐利可辨（验收 5）。
- 发光只作用于琥珀与极弱钢色，不引入任何新色相；不得出现 lens flare。

## 8. 逐效果技术规范（实现要点汇总）

### 8.1 描边 dash 显现
`pathLength="1"` + `stroke-dasharray="1"` + `stroke-dashoffset: 1 → 0`；
起点左上、顺时针；帧 1–48；`easeInOutCubic`；描边宽恒为 `3.5`、色 `#e6ecf3`。

### 8.2 拆解
对象 = 屏框四边 + 四螺钉 + 两立柱 + 琥珀横杠（共 11 原子）；方向/位移/旋转
严格按 6.1 表；位移与旋转同步；`easeOutCubic`；帧 54–82。

### 8.3 重组
11 原子回归第 3.1 节精确坐标；旋转归零；`easeInOutCubic`；帧 83–116；
可选 ≤0.6 单位过冲但必须连续；帧 116 完全复原。

### 8.4 缩放推进
整体绕 (480,270)；`1.00× → 1.18×`；等比；**`easeInOutCubic`**；帧 117–145。

### 8.5 发光
琥珀 `#f5a524` 外发光半径 ~5–6 px、强度 ≤0.28；钢色 `#e6ecf3` 极弱补光
半径 ~3 px、强度 ≤0.10；发光层在原图之下；帧 146–164 渐入；无第三种颜色、
无 lens flare。

### 8.6 最终锁定
沿用 `logo-lockup.svg` 构图（标 1.5× + `HBMZZ` 粗体等宽字 + 琥珀下划线）；
字高 ≥54 px、`#e6ecf3`；副标用 `#48525f` 或省略；帧 165–192 静止。

## 11. 实现顺序建议（给 intro-build）

1. 从 `logo-mark.svg` 拆出 11 个原子图层，锁定第 3.1 节坐标为回归基准。
2. 用 SVG/Canvas 逐帧渲染，按第 4 节帧号驱动各属性；24fps 导出 192 张 PNG/JPG。

4. 用 `logo-lockup.svg` 的构图逻辑绘制定格帧（帧 165–192）。
5. ffmpeg 合成静音 mp4（`-an`），抽帧校验 192 张。
6. intro-package 用与 `pack.py` 相同的结构产出 zip 与 `meta.json`。

## 12. 验收清单（逐条核对，全部通过方可交付）

1. **首帧非黑屏**：`f000001` 在深底上已有可见的屏框描边笔画，不是纯 `#0a0c0f` 空屏。
2. **末帧稳定**：`f000192` 与 `f000191` 像素一致；定格帧 HBMZZ 完整、无抖动/呼吸。
3. **HBMZZ 清晰可读**：等宽粗体、字高 ≥54 px、字距 8、`#e6ecf3`，无压缩糊字。
4. **琥珀横杠全程存在**：在阶段一淡入后、2a 飞散中、2b 重组中、2c 缩放中、2d 发光中
   的采样帧里都能定位到 `#f5a524` 像素，不淡出、不换色、不被遮挡。
5. **只用四品牌色**：逐帧采样，除 `#0a0c0f` 背景与半透明琥珀/钢色光晕外，不出现
   第五种彩色色相；钢色描边与 H 立柱细节在发光后仍锐利可辨。
6. **变形无跳帧**：2a→2b 的相邻帧位移连续；帧 116 主标精确回到 64 网格坐标；
   无瞬移、无闪烁、无半帧错位。
7. **缩放 easing 合规**：2c 使用 `easeInOutCubic` 或等价曲线，首尾速度为零，
   `1.00×→1.18×` 无过冲出安全区。
