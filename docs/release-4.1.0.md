# HBMZZ 4.1.0 — 贴墙的神盾屏，和一根两下就连好的线

> HBMZZ 4.1.0 发布，面向 Minecraft 1.12.2 / Forge 14.23.5.2847。
> 这一版把神盾（Aegis）遥测终端从「悬在空中」变成**贴墙安装的壁挂屏**：带金属外壳和墙面支架，
> 放置后可以在设置窗口里调**倾斜角、宽、高**，实时生效并存盘。
> 还新增了专用**神盾连接工具**——右键核心、右键屏幕，两下完成绑定。

| 内容 | 说明 |
|---|---|
| 贴墙壁挂屏 | 屏幕新增金属外壳（背板 + 四壁）和墙面支架，不再是一张悬空的光板 |
| 可调几何 | 设置窗口里调倾斜角（−45°~+45°）、宽、高（0.5~2.0 格），实时生效、存档保留 |
| 神盾连接工具 | 新物品「神盾连接工具」：右键 DFC 核心记录，再右键神盾终端绑定；潜行右键清除绑定 |
| 自动连接保留 | 原来 16 格内自动扫描绑定照旧，手动工具和自动扫描两种连法并存 |
| 版本升级 | 三处版本戳统一升到 4.1.0，产物 `hbmzz-4.1.0.jar` |

---

## 一、贴墙壁挂屏

旧版终端的方块本体不渲染，只有一块发光四边形浮在方块面前，看起来像悬空的光板。
4.1.0 给它补上了实体：

- 屏幕背后有**深色金属外壳**——背板加上下左右四壁，随屏幕尺寸一起变化，有真实厚度；
- 一根**支架**从屏幕背后伸向墙面，把它锚在墙上；
- 发光屏、霓虹边框、状态辉光都按当前宽高绘制，倾斜时整块屏连同外壳一起转。

一句话：现在它看着就是一台装在墙上的显示器，而不是贴在空气上的画面。

## 二、可调倾斜角 / 宽 / 高

普通右键打开设置窗口，新增「墙面安装」分区，三行 `− / +` 按钮：

- **倾斜角**：−45° 到 +45°，每次 5°，让屏幕抬头或低头；
- **屏幕宽 / 高**：0.5 到 2.0 格，每次 0.08 格，拼出你要的屏幅。

当前数值实时显示，点完底部有中文回执。快捷键：`Z`/`X` 调倾斜，`[`/`]` 调宽，`-`/`=` 调高。
所有调节服务端校验后写入存档，重启不丢；老存档没有这些参数时保持原来的外观。

## 三、神盾连接工具（新）

红石类物品，铁锭 + 红石 + 比较器即可合成，也可以从创造栏直接拿。

1. **右键 DFC 反应堆的核心**——工具记下核心坐标（悬浮提示会显示）。
2. **右键神盾终端**——把记下的核心绑定过去，屏幕开始显示这台堆的数据。
3. 想换回自动扫描，**潜行右键终端**清除绑定即可。
4. 工具是空的时右键终端，会直接打开设置窗口，所以它也顺手当遥控器用。

绑定写在终端自己的存档里，工具用完丢了也不影响。原来的**自动扫描**（16 格内自动找最近核心）依然有效，两种连法随便挑。

## 四、安装

| 步骤 | 操作 |
|---|---|
| 1 | **先删掉 `mods/` 里的旧 hbmzz jar**，再放进 `hbmzz-4.1.0.jar`（新旧同放会因重复注册崩溃） |
| 2 | 依赖 Forge 14.23.5.2847；DFC 监控需 NTM:CE（`[HBM的核科技社区版]`）≥ 2.5.0.5 + Cursed Addon |
| 3 | 独立配置在 `config/hbmzz-aegis.cfg` |
| 4 | 换 jar 后重启即可；几何参数是新增存档字段，老档兼容，无需清档 |
