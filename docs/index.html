// 01 — 这个模组里有什么

一块屏，三套控制体系，外加一堆顺手做的东西

看数据是一层，操控机器是另一层。前者从 1.x 一路长到现在，后者是把诅咒版的控制台移植过来之后才补齐的。

01

实时屏幕

方块正面不是贴图，是一台真在绘制的显示器。AWT 离屏画布 + 3 倍超采样，21px 读数、真圆环刻度、抗锯齿曲线同时出现在同一块面板上。

AHBSSMFI-OS 4 个视图 1–4 × 1–3 格

02

可缩放终端

右键打开终端，左列是控制、右半边是这块屏的实时预览——预览里的像素和你站在方块前看到的是同一份。页面、电源、尺寸全部服务端权威。

拖角 / 滚轮 / 双击 功率计绑定 融毁倒计时

03

面板工坊

第四页 04 自定义 留给你自己。控件怎么摆、什么时候报警，全部用「当 + 若 + 则」的积木规则描述，改完点保存才写进世界。

7 种控件 独立编辑窗口 预设库

04

机器控制面板

用数据线右键机器记录、再右键面板，在 A–F 六个槽位里绑定，然后拧旋钮就能真的操控 NTM 机器。13 种控件，事件通过反射桥发给上游。

13 种控件 跨模组机器桥 A–F 槽位

05

节点图控制台

从诅咒版（Leafia CE Addon）移植的整套控制台：25 种控件、运行时镜像的事件表、拖拽编辑的节点图，编译成可执行的节点网络。这上面也能放终端——第 26 种控件是本项目自己加的。

26 种控件 32 种节点 事件 → 节点图

06

枪械 / 线圈 / 喷气背包

顺带做的：制式枪械、Roblox 风格的加特林线圈与喷气背包。它们和监控屏共用同一套资源与配方体系，没有额外的依赖。

制式枪械 线圈：蓄力过载 耐久即燃料

07

视频广播器

红石上升沿一到，被选中的玩家屏幕当场黑掉，然后开始播一段视频。目标用命令方块那套选择器指定，视频放在客户端 config 目录里——纯 JRE 解码，不带原生库。

@a[r=32] 全屏接管 帧序列

08

红石音频（同一作者的另一只模组）

Redstone Audio 不是搬来的第三方模组，是本项目作者自己写的独立模组，以前单独发一枚 jar。2.9.0 起整套打在同一枚 jar 里：音频播放器、红石延迟器、结构加载器、自动化红石计算机、六色警报灯、防核门、广播器、DMR / F9 两台反应堆、电梯、监控、门禁、列车。播放器还多了 reasim——把音乐变成廉价喇叭的失真、工频哼声与房间回声。

191 个源文件 reasim 破喇叭 modid = rsaudio

09

黑客平板：不拉控制棒，直接改堆

右键打开一个终端，输入指令就能改写全图任意一台机器的数值字段——温度、通量、控制棒插入量、储能。它不按按钮也不经过机器的事件表，所以控制逻辑整段被绕过去。写入会被监测屏当场发现：先断链 3 秒，再让温度 / 储能 / 输出 / 发电显示 Err 30 秒；一条 cut 能让所有屏满屏 ERROR#！。

3.0.0 新玩法 反射写字段 可关：hacker.enabled

10

核事故系统：五块方块，八级代码

一颗全图只能有一颗的核弹、它的信号控制器、监视它的屏、广播设施代码的方块，以及一块一个业务字段都不存的事故显示器。因为谁都不保存副本，「所有屏幕显示一致」不是纪律而是结构——服务端一份状态，客户端一份副本，发的永远是整条记录而不是增量。

3.1.0 新系统 木斧蹲下联动 超时画 NO LINK

// 02 — 四步看到读数

从零到屏上有数

不装 NTM:CE 也能启动并打开终端，只是屏上会写「未找到堆芯」——它对本体的依赖是软的（after:hbm）。

装好前置

Minecraft 1.12.2 + Forge 14.23.5.2847 以上。想读 DFC 数据就装 NTM:CE；用诅咒版的客户端另需 MixinBooter —— 本模组自身不使用 Mixin。

丢进 mods

把 hbmzz-<版本>.jar 放进 .minecraft/mods。启动一次，配置会生成在 config/hbmzz.cfg。

放下监控屏

正面会自动开机并显示读数。16 格内有 DFC 核心就会自动绑定；想固定核心或读功率计，用监控数据线右键核心 / 红色电缆仪表，再右键监控屏。

打开终端调屏

右键监控屏打开终端：开关电源、切四个视图、改墙屏跨几格、拖窗口大小。想看板子之外的机器，再放一块机器控制面板。

// 03 — 它为什么不一样

几个刻意的选择

这些细节决定了屏上看起来是「一台设备」还是「一张贴图」。

离屏画布，而不是逐字绘制

全部内容用 Graphics2D 画到一张位图上，再作为单个纹理贴到一个 quad。 所以同一块面板上能同时有 21px 的大号读数、10px 的中文标签、真正的圆环刻度和带抗锯齿的曲线—— 这是用 FontRenderer 在 3D 里逐字绘制做不到的。

3 倍超采样 + 等比缩放

画布按 256×192 逻辑像素排版，实际纹理 768×576。墙屏无论跨 1–4 格宽、1–3 格高， 内容始终按 4:3 等比缩放居中，多出来的地方是黑色边框，不会被拉伸。

整面墙只渲染一次

只有控制器格有方块实体，其余格子是无实体的占位块。按构造就不可能重复绘制， 也不需要为每个格子各存一份状态。

不假装在算

融毁倒计时在坍缩阶段直接取 DFC 的 explosionIn； 稳定阶段按两颗催化剂损伤的实测增长速率推算，损伤不再增长时不显示预测， 而不是拿写死的速率假装在算。

链路指示灯

标题带和页脚都有 LINK OK / LINK SLOW / 数据中断，按最新样本的年龄变色。 屏幕停住的时候，它会直接告诉你停在哪一环。

事件日志不刷屏

客户端比较前后两帧，只在跨越阈值时记一条：温度等级变化、稳定度下降、 结构变化、燃料装卸、坍缩开始。平时一条都不写。

GPL-3.0，因为它必须得是

控制面板与节点系统逐文件移植自 NTM: 诅咒版（GPL-3.0），附属控件与节点来自 CE Addon（GPL-3.0 / LGPL-3.0）。 GPL 的衍生作品必须继续以 GPL 分发，所以本项目不能改成 MIT，也不能附加「禁止商用」之类的额外条款。 监控屏的渲染结构取自节枝的 DFC 工具，已取得作者书面授权。 内置的 Redstone Audio 不在此列——那是作者自己写的模组，不是第三方来源。
