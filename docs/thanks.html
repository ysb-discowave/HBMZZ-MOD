// 写给「我的世界晴天菊」

做模组这件事，大部分时间是安静的

改一行代码，等十几分钟编译，进游戏看一眼，再改回来。中间没有观众，也没有掌声， 屏幕上那台机器亮不亮，只有自己知道。

所以当有人明确地说「我支持这个」，是会被记住的。 「我的世界晴天菊」，谢谢你。

这句话放在官网上，是想让感谢留在一个看得见的地方，而不只是群里的一句回复。
