// 致谢 · ACKNOWLEDGEMENTS

谢谢你们.

一个模组能做到今天，从来都不是作者一个人的事。有人愿意在旁边看着，愿意说一句「这个不错」；也有人什么也没说，只是留了下来——这些看着很小的事，其实都是很实在的鼓励。它们会让一个改代码改到半夜的人，忽然觉得手里的活儿是有人在看、有人需要的。

这一页，想认认真真地记下三个名字。不是走流程，也不是客套，是因为这三份好，我一直都记着：我的世界晴天菊、上、还有星座云（DSH-Tiny）。最后，也谢谢正在读这段话的你。

// 01 · 写给「我的世界晴天菊」

做模组这件事，大部分时间是安静的

LETTER / 001

改一行代码，等十几分钟编译，进游戏看一眼，屏幕没亮，再改回来。中间没有观众，也没有掌声。某个方块到底亮不亮、某段逻辑到底跑没跑通，除了自己，没人知道，也没人在意。做模组这件事，大部分时间就是这样一个人的安静。

也正因为这样，当有人明确地说「我支持这个」，是会被牢牢记住的。那不是随手一句客气话，是有人在茫茫多的模组里停下来，认真看了它一眼，还愿意把那句话说出来。

「我的世界晴天菊」，谢谢你。谢谢你把这句话说出口，谢谢你在那些没人鼓掌的日子里，替它鼓了一次掌。

把这份感谢放在官网上，是想让它留在一个看得见、也不会被刷掉的地方——而不只是群里一闪而过的回复。哪天你偶然回来看，它还在。这就是我能想到的、最郑重的「谢谢」。
