## 本次变更

把项目版本标识从 4.1.0 回退到 3.9.0：

- `build.gradle`、`HBMZZ.java`、`mcmod.info` 三处版本戳统一为 3.9.0；
- 构建产物改名为 `hbmzz-3.9.0.jar`；
- 功能代码、网络协议、存档结构均未改动。

这是一次版本号调整，不是功能回退——游戏里的监控屏行为和 4.1.0 完全一样。

## 几何调节实时生效

旧版在菜单里点 `−`/`+` 后要等服务端同步回来才变，得退出菜单才看到效果。现在点一下：客户端立即更新预览（画面和读数下一帧就变），同时把同一个值发给服务端存档并广播。两端用同一套范围钳制，回包不会让数值跳回去。鼠标按钮和 Z/X、[ / ]、- / = 快捷键都一样实时。

## 保留的能力（来自 4.1.0）

- **贴墙壁挂屏**：终端带金属外壳和墙面支架，不再悬空。
- **可调几何**：设置窗口里调倾斜角（−45°~+45°）、宽、高（0.5~2.0 格）。
- **神盾连接工具**：右键核心记录、右键终端绑定、潜行右键清除；自动扫描照旧。
- **全息监控画面**：面积图、渐变、辉光、扫描光带、中文界面。

## 安装

| 步骤 | 操作 |
|---|---|
| 1 | **先删掉 `mods/` 里的旧 hbmzz jar**，再放进 `hbmzz-3.9.0.jar`（新旧同放会因重复注册崩溃） |
| 2 | 依赖 Forge 14.23.5.2847；DFC 监控需 NTM:CE ≥ 2.5.0.5 + Cursed Addon |
| 3 | 独立配置在 `config/hbmzz-aegis.cfg` |
| 4 | 换 jar 后重启即可，无需清档 |
