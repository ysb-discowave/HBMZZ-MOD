# HBMZZ 4.1.0 交付文档

日期：2026-11-21
基线：4.0.0（上一版为全息视觉升级 + 黑屏致命 bug 修复版）

这一版做了四件事：版本号升到 4.1.0、监控屏改成贴墙壁挂式、放置后可调倾斜角/宽/高、新增专用连接工具。

## 一、版本号升级到 4.1.0

三处版本戳统一更新，避免构建产物和 Mod 列表里版本对不上：

- `build.gradle`：`version = '4.1.0'`
- `HBMZZ.java`：`VERSION = "4.1.0"`
- `mcmod.info`：`"version": "4.1.0"`

构建产物从 `hbmzz-4.0.0.jar` 变为 `hbmzz-4.1.0.jar`。

## 二、监控屏改为贴墙壁挂式（不再悬空）

原来的问题：屏幕只是画在方块面前的一张发光四边形，方块本体渲染为 INVISIBLE，看上去像悬在半空的一块光板，没有"贴在墙上"的实体感。

改法（`AegisRenderer.java`）：

- 屏幕不再定位在方块中心，而是绕**墙面**（局部 +Z 的 0.5 面）做枢轴，留一点安装间隙，让它像真显示器一样靠在墙上。
- 新增 `wallBracket()`：从屏幕背后伸向墙面的金属支架，把屏幕"锚"在墙上。
- 新增 `backing(halfW, halfH)`：屏幕背后的深色金属外壳（背板 + 上下左右四壁），宽度/高度跟着可调参数走，给出真实厚度。
- 原有的霓虹边框、加色辉光、发光屏幕四边形全部改成按当前宽/高绘制，不再写死 0.46。
- 屏幕尺寸、倾斜、外壳、支架一起旋转，倾斜时整块屏连同外壳一起动。

配套的 `getRenderBoundingBox()` 放大到足以容纳最大尺寸 + 倾斜摆动，避免调大后玩家走过时屏幕被视锥裁剪而消失。

## 三、可调倾斜角 / 宽 / 高（放置后设置，存盘）

数据层（`TileAegisTerminal.java`）：

- 新增三个持久化字段：`tilt`（倾斜角，−45°~+45°，默认 0）、`panelWidth`（宽，0.5~2.0 格，默认 0.92）、`panelHeight`（高，0.5~2.0 格，默认 0.92）。
- `setGeometry(tilt, width, height)` 统一 clamp，无变化则不markDirty/不同步。
- 三个字段写进 NBT（`aegisTilt` / `aegisWidth` / `aegisHeight`），随 `getUpdateTag` 同步到客户端；老存档没有这些键时回退到默认值，保持原外观。
- `getUpdateTag` 走 `writeToNBT`，所以设置窗口打开时推的权威状态会自动带上几何参数。

网络层（`AegisSetupPacket.java`）：

- 新增 `TILT` / `WIDTH` / `HEIGHT` 三个 action，`value` 用定点数传（角度 ×10，格数 ×100），服务端 clamp 后写入。仍是服务端权威 + 距离校验（12 格），伪造包只能改玩家正站着的终端。

界面层（`GuiAegisTerminal.java`）：

- 窗口加高到 302px，新增"墙面安装"分区，三行 `− / +` 按钮分别调倾斜角 / 宽 / 高，实时显示当前数值和操作回执。
- 快捷键：`Z`/`X` 调倾斜，`[`/`]` 调宽，`-`/`=` 调高；原有 `1-4`、`Q/E`、`P` 不变。

## 四、专用连接工具「神盾连接工具」

新物品 `aegis_linker`（`ItemAegisLinker.java`），复用监控连接工具的纹理，红石类创新栏，可合成（铁锭 + 红石 + 比较器）：

- **右键 DFC 核心**：把核心坐标记进工具 NBT。
- **右键神盾终端**：把记录的核心坐标写入终端绑定（服务端校验、写入终端 NBT，工具丢了也不影响）。
- **潜行右键终端**：清除绑定，恢复自动扫描。
- **空白工具右键终端**：退化为打开设置窗口，兼作遥控器。
- 悬浮提示显示已记录的核心坐标。

接线：注册进 `ModContent`（字段 + 注册 + 配方）、`ClientProxy` 的三张并行表（items / itemModels / METAS）、语言文件（中英），并新增 `models/item/aegis_linker.json`。自动扫描连接（半径 16 格）保留不变，两种连法并存。
