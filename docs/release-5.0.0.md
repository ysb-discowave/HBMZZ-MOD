> HBMZZ 5.0.0 发布，面向 Minecraft 1.12.2 / Forge 14.23.5.2847。
> 这一版把「AI 管机器」从纸上谈兵变成真闭环：AI 控制节点采样上报、异常时全图 TTS 语音告警，
> 还能通过反射直接操作 DFC 的稳定器 / 接收器 / 发射器 / 核心启停；新增 AI 终端物品，

## 一、AI 控制节点（新方块）

`ai_control_node` 绑定一台机器后周期采样：DFC 核心走 AegisProbe 采样（温度/稳定度/能量/燃料），通用方块实体走 NBT 数值。每轮把机器名、数值、相位打包成 JSON POST 到可配置的 AI 接口（endpoint / key / model 都在 `/ai` 命令里调，写进 `config/hbmzz-ai.cfg`）。

AI 的回复是约定的 JSON 协议：`abnormal`（异常判定）、`message`（给玩家听的一句话）、`reason`（判定理由）、`level`（严重度）、`display`（上屏内容）、`actions`（要执行的动作）。

- 回「正常」：数据上监视屏，安静。
- 回「异常」：服务端 TTS 合成一次语音，流式下发全服——全图同时响；聊天栏给所有客户端视觉脉冲 + 文字。
- 动作字段命中已注册动作名时，`AiAction` 在 `autoScram` 门控范围内执行；兜底 SCRAM **默认关**，要开 `/ai arm`。

## 二、AI 直接接管 DFC

`DfcControl` 用反射调 NTM 的内部接口：稳定器、接收器、发射器的开关与档位，核心的启停。反射钩子按 NTM/CE 的类与字段签名解析，命中不了就落回「只报告」，不会崩。

设计原则一句话：**默认 AI 只有嘴，没有手**。`autoScram` 不开时，AI 能说的最多是「建议急停」；开了之后失控判定才允许它自己动手。

## 三、AI 终端（新物品）

`hbmzz:ai_terminal`，右键开 GUI：

1. 输入自然语言指令（如「查一下 3 号堆温度」）；
2. 服务端把当前绑定机器的数值快照 + 你的个人提示词拼成完整提示词发给 AI；
3. 回复回显在终端窗口，异常判定同步触发全图语音。

提示词三层：**预设**（内置默认「只报告，等待指令」）→ **全局自定义**（服务器级）→ **个人覆盖**（按玩家 UUID 存），一层盖一层，改完下一句立即生效。

## 四、核弹档位制 + 湮灭波

- **威力 6 档**：试验 / 战术 / 战略 / 重型 / 破芯 / 毁档（DELTA）。爆炸力上限从 48 提到 120。
- **引信 6 档**：5 / 15 / 30（默认）/ 60 / 120 / 300 秒，原来写死的 5 秒终于能选了。
- 操作：斧子右键（不蹲）= 切威力档，空手蹲右键 = 切引信档；倒计时中锁定，先中止再改。记录/联动/中止手势保留。
- 档位存 NBT，老存档按 yield/fuse 就近回退，不加网络字段。

**毁档不再是「大号弹坑」。** DELTA 引爆后，服务端 `NukeAnnihilation` ticker 从爆点向外逐 tick 清除半径 512 内所有**已加载区块**的方块与实体，只留基岩/屏障，连地形一起抹掉。每 tick 限量（默认 65536 坐标）不卡死服务器；未加载区块不强制载入（引擎限制）。按维度一实例，世界卸载/停机清理，换存档不留波。

## 五、神盾贴墙壁挂屏（4.1.0 特性并入本版）

- 屏幕加深色金属外壳（背板 + 四壁）与墙面支架，不再是一块悬空光板；
- 设置窗口调倾斜角（−45°~+45°）、宽、高（0.5~2.0 格），实时生效、存盘；
- 新物品「神盾连接工具」：右键核心 + 右键终端两下绑定，潜行右键清除，16 格自动扫描照旧。

## 六、官网 reasim 工作台混响

`docs/tools.html` 的 reasim 音频工作台加了独立混响后级：8 条互不可通约梳线（延迟 GCD=1）并联 + 5 级一阶全通 + Freeverb 式反馈阻尼低通，衰减（RT60）/ 音调 / 预延迟 / 混响量四个滑条。网页侧独立开关，游戏内 TTS 音色链不受影响。

## 七、网易云音乐网络音源

音频播放器新增网络音源：搜歌 → 下载 → 播放，全程在 GUI 里完成，不碰命令行。

- **搜索**：播放器设置窗多了「网易云搜索」一行，输入关键词回车出结果（每次 8 条、可翻页）；与本地搜歌、广播输入三个框 Tab 互斥切焦点。
- **下载缓存**：选中歌曲后后台抓取直链、下载 mp3 到 `config/rsaudio/netease/<id>.mp3`，再次播放直接读缓存，不重复下载。
- **播放**：网易云歌曲不进 `audio/` 目录、不注册 `sounds.json`，靠前缀 `nmc_<id>` 走独立链路——mp3 经 formats 层解码成 16-bit PCM，再过一遍 reasim 破喇叭 DSP（增益→失真→电流声→沙沙声→回声→软限幅），与内置 ogg 获得一致的「破喇叭」扬声器真实度；reasim 关闭时 DSP 纯透传。
- **可用性**：VIP 专属 / 无版权曲直链会返回非 200，按提示跳过即可。

## 八、安装

| 步骤 | 操作 |
|---|---|
| 1 | **先删掉 `mods/` 里的旧 hbmzz jar**，再放进 `hbmzz-5.0.0.jar`（新旧同放会因重复注册崩溃） |
| 2 | 依赖 Forge 14.23.5.2847；DFC 监控与 AI 控制需 NTM:CE（`[HBM的核科技社区版]`）≥ 2.5.0.5 + Cursed Addon |
| 3 | 独立配置：`config/hbmzz-aegis.cfg`（神盾）、`config/hbmzz-ai.cfg`（AI，`/ai` 命令写入） |

## 九、已知问题

- AI 反射控制 DFC 的钩子命中取决于 NTM/CE 实际版本；命中不了时自动落回「只报告」，`/ai selftest` 可以逐项点验。
- 湮灭波只清已加载区块——没加载到的区块炸不到，这是引擎限制，不是省略。
- `autoScram` 默认关是有意的：AI 误判自动急停的代价比手动急停高。
- 网易云直链依赖 163 API：VIP 专属 / 无版权歌曲取不到直链，界面上会提示跳过。
