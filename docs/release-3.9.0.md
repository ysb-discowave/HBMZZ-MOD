# HBMZZ 3.9.0 — 贴墙实体屏、一格步进，和独立熔毁预测 / 自动停堆

> HBMZZ 3.9.0，面向 Minecraft 1.12.2 / Forge 14.23.5.2847。
> 屏幕真正贴墙、侧视有实体；宽/高每次调一格；并新增一套完全独立的核心熔毁预测与自动停堆。

| 内容 | 说明 |
|---|---|
| 贴墙实体屏 | 背板贴墙面、外壳填满整格厚度，倾斜枢轴在墙面；渲染关闭背面剔除，侧视/斜视都是实体，不再是空气或滚木 |
| 一格步进 | 右键菜单宽/高每次 +1/-1 格，范围 1~32 格；倾斜角每次 5°；实时生效并存盘 |
| 熔毁预测 | `/coreguard forecast`：按升温斜率预测多少秒后到熔点 |
| 自动停堆 | `/coreguard scram`：>10000°C 每秒降 5000°C、>5000°C 每秒降 2000°C，一直到 0 |
| 停堆可视标识 | 自动停堆运行中，监控屏温度读数上方显示闪烁的"自动停堆"徽章，解除后自动消失 |
| 权限 | 停堆指令权限 0，任何玩家可用；旧 `/aegis scram` 作为兼容别名指向同一实现 |
| 版本号 | 三处版本戳统一为 3.9.0，产物 `hbmzz-3.9.0.jar` |

## 一、屏幕贴墙、侧视不再是空气

之前屏幕浮在方块朝玩家那一面、离墙接近一整格，看着像悬空薄片，侧面几乎看不见。现在背板贴在墙面（方块贴墙那一侧），外壳向外填满整格厚度、正面只露一点唇边；倾斜绕墙面转，背板始终贴墙。渲染时关闭背面剔除，从侧面、斜侧面都能看到带厚度的金属盒体。

## 二、宽 / 高每次调一格

右键终端设置窗口里，宽和高每次点 + / - 增减 **1 格**（范围 1~32 格），倾斜角每次 5°。调节实时生效：画面和读数下一帧就变，同一个值同步到服务端存档并广播，两端用同一套范围钳制，不会跳回去。快捷键 `[` `]` 调宽、`-` `=` 调高、`Z` `X` 调倾斜，同样是一格步进。

## 三、熔毁预测时间（新）

```
/coreguard forecast
```

对附近最近的 DFC 核心采样，按升温斜率预测**多少秒后达到熔点**：

- 温度持续上升：显示"约 N 秒后达到熔点（+X.X °C/秒）"。
- 温度没上升：显示"暂无风险"。
- 已到熔点：显示"临界！"。

第一次查询是"采样中"，隔一秒再查就有结果（斜率需要两次采样）。

## 四、自动停堆（新，重写）

旧的 `/aegis scram` 之所以"没用"，是因为它写的是原版 HBM 的 `heat` 字段；反编译确认 CE 版的真实温度在 `double temperature` 字段、由 `setDFCTemperature(double)` 写入，写 `heat` 根本不影响真实温度。这一版全新实现（独立包 `com.hbmzz.guard`，不复用监控屏代码），直接写真实温度：

- 温度 > **10000°C**：每秒降 **5000°C**。
- 温度 ≤ 10000°C（>5000°C）：每秒降 **2000°C**。
- 一直降到 **0** 并保持。

指令（权限 0，人人可用）：

| 指令 | 作用 |
|---|---|
| `/coreguard scram` | 对附近最近的 DFC 核心启动停堆 |
| `/coreguard forecast` | 查熔毁预测时间 |
| `/coreguard status` | 查看正在停堆的核心、温度和已运行秒数 |
| `/coreguard off` | 解除本世界的所有停堆 |

旧写法 `/aegis scram [off|status|forecast]` 仍然可用，指向同一套新实现。停堆按维度+坐标建会话，区块卸载时暂停、核心消失或停服时自动清除。这是应急刹车，通过写核心真实温度实现，不替代反应堆自身的控制逻辑。

**停堆时的画面提示**：只要某台核心正在被自动停堆，连着它的监控屏会在温度读数上方亮起一个闪烁的"自动停堆"徽章（红底呼吸边框），一眼就能看出这台正在强制降温；执行 `/coreguard off` 解除后徽章自动消失。

## 五、安装

| 步骤 | 操作 |
|---|---|
| 1 | **先删掉 `mods/` 里的旧 hbmzz jar**，再放进 `hbmzz-3.9.0.jar`（新旧同放会因重复注册崩溃） |
| 2 | 依赖 Forge 14.23.5.2847；DFC 监控需 NTM:CE ≥ 2.5.0.5 + Cursed Addon |
| 3 | 独立配置在 `config/hbmzz-aegis.cfg`；自动搜索半径默认 48 格，老存档自动从 16 迁移 |
| 4 | 换 jar 后重启即可，老档兼容 |
