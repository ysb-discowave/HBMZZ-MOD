## 一、神盾遥测终端（从零重写）

旧的 `dfc_monitor` 一行代码都没留。整个 `com.hbmzz.aegis` 包是重新设计的：独立的遥测数据结构、反射探针、配置和渲染管线。

- **一面会动的屏**：深空渐变背景上叠着缓慢漂移的网格和一条上下扫过的光带；标题「神盾」带辉光，右上角状态灯随连接/加载/篡改呼吸。
- **三页内容**：
  - 概览页——堆芯温度大字带径向光晕（按熔点比例由青转红）、稳定度、能量、温度趋势面积图；
  - 组件页——各部件计数块 + 冷却剂/慢化剂罐进度条；
  - 诊断页——催化剂磨损、功率计、信号完整性、预测信息。
- **危险状态很显眼**：坍缩、爆炸倒计时或链路被篡改时，整框红色脉冲、四角角标转红，底部弹出「堆芯坍缩 / 立即撤离」横幅。
- **数据安全**：采样在服务端做，无人观看时不跑反射；网络消息独立编号，客户端走反射桥，专用服务端不会因加载客户端类而崩。

## 二、全中文右键配置菜单

普通右键打开配置界面，潜行右键快速翻页。

- 一屏显示连接状态、绑定坐标 / 自动扫描、堆芯温度（分段渐变 + 熔点刻度）、稳定度、能量、当前页面、电源开关。
- 五个按钮：绑定最近核心 / 解除绑定 / 切换页面 / 电源开关 / 完成，点完底部给一条中文回执。
- 快捷键：`1~4` 对应四个动作，`Q` / `E` 翻页，`P` 电源，`Esc` 关闭。
- 打开瞬间主动拉一帧权威状态，停留期间定时补拉，不会停在「等待数据」。

## 三、怎么连到你的 DFC 反应堆

1. 把神盾终端放在核心附近——默认会在 16 格内自动扫描并绑定 `TileEntityCore`。
2. 没自动连上就右键终端 →「绑定最近核心」手动指定；连错了用「解除绑定」重来。
3. 温度按摄氏度显示，熔点是判断高低的基准（默认 2250°C），比例越高字越红、光晕越强。
4. 读数来自核心的 DFC 接口；核心刚放下还没点火时温度可能显示为 0，属正常，装料运行后即有读数。

## 六、本轮修掉的问题

- **永久黑屏**：纹理上传时间戳用了 `Long.MIN_VALUE`，`now - Long.MIN_VALUE` 溢出成负数，节流判断恒为「太快」，纹理一帧都没上传过。改为初始 0 + 首帧标记。
- **画面每 4 秒才动一次**：离屏画布每帧重绘但 GL 上传被 4 秒节流卡住，动画只有 1/4 帧。改为 16ms 上传上限。
- **自动扫描时篡改状态不显示**：查询键传成「手动绑定坐标」，自动扫描时为 null。改为按实际读到的核心坐标取键。
- **换存档泄漏 GL 纹理**：世界卸载时补上 Aegis 渲染器缓存清理。
- **报警横幅 / 流体罐被页码栏盖住**：调整布局后完整可见；「稳定」的方块符号改用「≈ 稳定」。
- **温度读取兜底**：核心温度字段尚未填充时回退到原版 `heat`，坍缩/倒计时补上 `meltdownTick`/`field` 兜底。
